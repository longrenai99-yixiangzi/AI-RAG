# Native table column labels and verified source-page preview

Completed on 2026-10-24, following work begun on 2026-10-23. Scope: an explicitly selected, already-admitted PDF table. This is a local single-user trial update, not a formal-service or whole-library release.

The existing page text had lost column boundaries and mixed wrapped header labels with diagonal watermarks. The new local route reads the selected page's native grid and character geometry, excludes rotated watermark text, and joins wrapped header labels. It returns only column names; template examples and empty cells are not project values. No real table title, column names, count or page number is hardcoded in the rule.

Supported layout is deliberately limited to one unmerged header row beginning with a serial-number label. Ambiguous tables, changed source bytes, wrong counts and unsupported project-value, mandatory-field, exclusion, explanation or completion requests do not become complete answers. New and old generation previews cannot pay a model to invent fill values from these labels. The original document-admission, named-source and version filters remain in force.

References retain the original-file link and a verified PDF page fragment. A separate read-only source-page image preview is available for citations with a known PDF page. It verifies the current version before and after bounded local rendering and uses no-store caching; original bytes and watermarks remain unchanged. A shared lock serializes the new native-PDF reads. Invalid pages, non-PDFs and source changes are rejected.
