# V2 INTERNAL TRIAL GUIDE

日常访问 `http://127.0.0.1:8010/knowledge-os`，直接问答可访问 `http://127.0.0.1:8010/ai`。

旧版 `/v2-trial` 仅作底层诊断备用入口。

1. 在新 UI 的“AI问答”页面输入真实业务问题。
2. 普通用户查看结论、回答状态和引用；点击引用可查看文件位置和证据摘录。
3. 答案或引用有问题时，展开“提交问题反馈并纳入修复闭环”：选择反馈类型，填写问题说明；正确答案或关键事实可选，当前问题、回答和引用会自动附带。
4. “资料缺失”和“答案冲突”只形成待审核 Proposal，不会发布知识。
5. 管理员可记录 APPROVE / REJECT / DEFER / MERGE；即使 APPROVE 也不会自动发布或改写索引。
6. 如需快速关闭 V2，将 `V2_VERIFIED_RAG_ENABLED` 设为 `false` 并重启 8010；8000 不受影响。
