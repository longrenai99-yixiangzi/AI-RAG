# 二、执行总原则

Codex必须遵守：

1.  不修改原始知识库文件。
2.  不重新安装CUDA/PyTorch。
3.  不更换BGE-M3和Reranker。
4.  不引入Docker。
5.  不一次性重构全部代码。
6.  每个Task完成后测试并提交Git。
7.  遇到架构冲突先报告，不自行扩大范围。
