# NEW-05：问答、来源与更正的运行范围收口

日期：2026-09-27。范围：代码、隔离检查，以及经 Owner 明确授权的本机 8010 临时在线验收。8000 未启动或写入；在线服务已停止。

## 调用链与复现

| 入口 | 修复前实际读取 | 隔离复现结果 | 修复后口径 |
| --- | --- | --- | --- |
| 普通问答 | 配置决定 V1 或冻结候选 | 候选主答可返回候选哈希 | 统一经 `_answer_current_runtime`；保留实际运行指针 |
| 来源目录、预览 | V1 文档/切片，接口最多显示前 50 条 | 候选引用的 `source_id` 在 V1 中可缺失；较后位置的引用无法从来源页精确定位 | 按当前主答的原子证据列目录；可用 `evidence_id` 精确预览同版本引用 |
| 搜索、知识节点 | 本地登记来源和活跃更正，加候选证据 | 冻结候选可混入未纳入的本地更正 | 候选只显示候选证据；V1 搜索过滤到实际运行版本 |
| 审核更正 | 本地存储直接写 `ACTIVE` | 候选主答冻结，审核成功并不会注入候选 | 候选模式写 `PENDING_CANDIDATE`；V1 模式仍按原流程生效 |
| 更正、增长、批量回归 | 固定 V1 答案入口 | 与候选普通问答运行身份不同 | 共用当前主答入口；记录运行指针；来源未纳入则 `NOT_READY` |
| 撤回、换版、回滚 | 本地状态可变，候选文件冻结 | 本地撤回无法立即修改冻结候选 | 本地待纳入知识撤回/换版后须复核；冻结候选仍按其原版本可追溯 |

候选主答中的“回归通过”只表示当前候选回答满足该回归断言，不表示审核更正已纳入候选。来源页将本地来源状态与当前主答收录状态分开显示。候选已冻结时，本地来源刷新或撤回须在下一版候选中体现，不能称作当前候选已变更。

在线对照另发现一项既有 V1 答案质量问题：项目限定的问题得到 `PARTIAL_ANSWER`，引用了另一项目资料，而同题候选回答引用了对应项目资料。该差异不是本次接口运行范围修复引入的；应进入后续检索与项目范围诊断，不能将 V1 的部分回答当成已核实业务答案。私有验收包保留 `query_run_id`、引用身份和原始响应，公开仓库只保留上述不含原始资料的摘要。

后续诊断项：核对 V1 项目名识别、跨项目候选证据过滤和引用校验；用独立项目/年份样本复现后再决定修复位置。该项不改变 NEW-05 已验证的运行身份与更正生效边界。
