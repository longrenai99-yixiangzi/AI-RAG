# 知识库后续工作任务操作指导手册（公开版）

本手册对应已执行的NEW-01～12和DEP-01/02，提供复核及后续操作步骤；当前完成状态见[NEXT_WORK_STATUS](NEXT_WORK_STATUS.md)。本页使用参数化目录，不包含业务原件、逐题答案或机器私有位置。

## 角色与材料约定

- Owner：内容事实与适用边界、真实业务可用性、具体正式版本采用、独立备份位置。
- Codex：完整读取已给材料、源码/解析/索引修复、核验、封包、部署/恢复、台账与Git发布。
- `<CODE_DIR>`：清理后公开源码副本；`<RUN_DIR>`：受控执行材料；`<SOURCE_DIR>`：只读知识源；`<DEPLOY_DIR>`：具体获准的私有部署目录；`<BACKUP_DIR>`：经核对的恢复材料目录。
- 指令与文档内容分开：旧包批准不自动批准不同新包；执行按最新用户明确范围。已确认事实不反复索要。

## 每项任务的执行方式

先核当前状态与授权，保存基线；再完成技术动作、必要证据和实际结果；更新台账。发生实质事实冲突或未授权正式范围，准备具体差异供Owner判断。未测量、不具备或尚未部署的结果如实记录。

### NEW-01：基线与清点

1. 核当前版本、责任人和本项批准范围。
2. 保存代码差异、配置/门禁/Owner决定与关键文件副本；大资产按路径、SHA、容量及恢复方法登记；保留未提交历史，分类而不自动清理。
3. 保存实际产物、检查结果和限制；失败现场保留，不冒称全部修复。
4. 按任务台账验收，人工依赖列为待办，后续执行者能从记录续接。

## 机器与人工时间

机器执行、人工审核、外部资料等待和自然使用日分别统计。早期四周为已撤销的粗略日历安排，不代表Codex需连续运行四周或Owner人工做四周。模型/浏览器检查耗时不等于全任务主动时间，无完整记录时写未测量。

## 检查与停止条件

明确候选和封包身份、来源版本、实际服务、输出必需事实、引用定位及记录保留。错项目/年份、未知值当事实、撤回知识继续采用或恢复失败时停止扩大受影响范围，保留现场，按获准预案处理。控制测试、离线模型、真实浏览器及Owner业务评价互不替代。
