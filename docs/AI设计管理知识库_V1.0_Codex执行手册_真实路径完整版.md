# 7. Answer Engine重构

建立：

Answer Router。

问题类型：

    FACT_QUERY

    POLICY_QUERY

    CASE_QUERY

    METHOD_QUERY

    GENERAL_QUERY

规则：

## FACT

直接查询事实库。

例如：

项目实施单位。

禁止调用LLM猜测。

## POLICY

根据制度资料回答。

必须引用来源。

## CASE

总结案例。

## METHOD

总结方法。

## 无答案

明确说明：

知识库暂无可靠依据。
