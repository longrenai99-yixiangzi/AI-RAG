# 本地使用、启动与恢复

> 2026-10-12：本页保留既有启动、恢复流程。当前正式8000为C包 `2cd04d6c`，最新X包 `2a9e3c62` 在8022试用；身份及验收以[当前状态](CURRENT_RELEASE_STATE.md)为准。新增工作台的日常操作见[逐步使用手册](OPERATIONS_GUIDE_20261012.md)，公开副本装配见[装配说明](PRIVATE_DATA_ASSEMBLY.md)。

## 使用

1. 在已部署的同一台电脑打开正式入口 `http://127.0.0.1:8000/ai`；8010为内部试用。
2. 提供项目、对象、时间和问题条件；已有对话记录保留。版本替换后重新发送问题核对新答案，不能把旧缓存回答当新版本运行结果。
3. 查看已确认与证据不足部分，展开引用，按精确证据和版本查看来源；通过同版原件副本核对位置。
4. 错答/漏答/引用不对应时登记反馈、期望事实和可核原件。反馈保存不等于自动发布知识或获得Gold。

## Codex启动与停止

1. 使用本机已批准固定包的实际控制入口，不直接用旧 `app.main` 命令替代。
2. 核清单SHA、依赖/模型、端口归属和批准目录。默认只读precheck，通过后才按具体授权serve。
3. 服务进程启动后等模型和候选就绪；健康应报告实际候选/模式/模型。仅文件可读不是服务就绪。
4. 停止只针对当前所属端口进程。正常停启保留问答和反馈，不调用恢复清空。

## 状态恢复与版本回退

1. 停止获准所属服务后保存最新状态，核所有文件SHA、问答/反馈编号。
2. 模拟或故障状态归档保存，恢复指定最新快照；原件和旧索引保持。不能把部署前无状态快照覆盖已有真实记录。
3. 重启核候选、同版引用及代表题，再核真实记录保留。回退版本需使用其批准入口和依赖，不混用新旧数据。
4. 独立灾备复制运行版本、可回退版本、共享模型/环境、最新状态及指纹清单；空间按当前内容算。收到外部目录后逐项验SHA并做实际恢复问答。

本机私有绝对路径、精确逐题记录和恢复授权保存在本机材料。公开源码与装配模板提供实现，真实目录和封包由使用者提供。
