## 4. 两个必须先解决的阻塞项

### 4.1 OCR 依赖缺失（用户已拍板开启 OCR）

```
pytesseract : MISSING(ModuleNotFoundError)
pdfplumber  : MISSING(ModuleNotFoundError)
PyMuPDF     : AVAILABLE
```

`auto_ocr: true` 现在开了也不会生效——**需要先安装依赖**。
且 tesseract 还需要 Windows 二进制 + 中文语言包（`chi_sim`），并配置路径。

### 4.2 老格式 .doc / .xls / .ppt 无法解析

约 1,700 个文件。可选方案：
- 用 LibreOffice 批量转换为 .docx/.xlsx/.pptx（需安装 LibreOffice）
- 或接受这部分不入库，在报告中标注为已知缺口
