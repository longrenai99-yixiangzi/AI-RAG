- 问“《某文件》这份资料主要讲了什么”时，按指定文件找正文；文件名中的年份、人数、项目名不再误变成统计条件。

## 怎样试用

1. 在本机打开 `http://127.0.0.1:8023/ai`，确认页面底部显示“指定资料原文选读 Z扩充”。原8022可继续使用。
2. 用书名号写清文件名，例如“《示例培训.pdf》这份资料主要讲了什么？”；通用问题无需强制选择项目。
3. 出现同名提示时先补扩展名；仍同名，从资料来源复制完整路径，用“《完整路径》这份资料主要讲了什么？”再问。完整路径只能选中已登记来源，不能读取任意本机文件。
4. 点击引用，核对位置与版本，再打开原件。表头选读不表示表格中的所有记录已总结。
5. 看到“部分回答”或“正文无法读取”时，按提示查原件；已有问题和反馈不必重复提交。
