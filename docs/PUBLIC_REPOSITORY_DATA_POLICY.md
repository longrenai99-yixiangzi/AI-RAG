# 公共仓库的数据范围

本仓库保持公开，保存通用应用代码和架构资料。原始知识库资料及其派生内容不进入公开 Git 历史，包括来源摘录、文本切片、索引和向量；逐题问题、答案、引用、运行日志、Trace 和人工复核记录也不公开。

本机运行数据默认保存在仓库外，或保存在已获准的受控存储中。`evaluation/`、`data/` 和 `logs/` 下的运行产物不提交。PDF、Word、Excel、PowerPoint 等测试附件只有在确认是合成数据、且无个人或客户信息后，才可进入公开仓库。

公开汇总指标必须先经内容 Owner 审核，并确认不含逐题内容、可还原的来源信息、内部绝对路径或个人联系信息。源码中的源文件映射应保持通用，不写入客户项目名称或本机路径。

现有公开分支历史已清理并重写。协作者应从清理后的分支重新克隆；不要把旧克隆上的分支合并回新历史。GitHub 缓存、Pull Request 引用、fork 和旧的本地克隆可能仍保留旧对象，分支重写本身不能清除这些副本。
